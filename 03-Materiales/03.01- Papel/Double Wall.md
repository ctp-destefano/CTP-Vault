# Double Wall

El **Double Wall** es un [[Corrugado|cartón corrugado]] con dos capas de [[Flute]] y tres liners (5 capas en total).

Se utiliza para fabricar cajas con mayor rigidez y resistencia que las de Single Wall.

En CTP trabajamos principalmente con:

- **BC ECT:** combinación de B Flute y C Flute.
- **CB ECT:** combinación de C Flute y B Flute.

El orden de las letras puede indicar la posición de las flautas, según la nomenclatura utilizada.

## Qué tener en cuenta

- **[[Caliper]]:** tiene mayor espesor y necesita más espacio para los dobleces.
- **[[Inside Loss - Outside Gain (Descuentos)|IL / OG]]:** requiere compensaciones propias; no usar automáticamente las de Single Wall.
- **Creases:** comprobar que el material doble correctamente sin romperse.
