**Nombre técnico:** Security Printing Ink

Tinta con propiedades de verificación o autenticación, dependientes de su tecnología específica. se aplica en la [[Heidelberg speedmaster]]
![[Pasted image 20261111104110.png]]
## Para qué se utiliza
Elementos antifalsificación, identificación o control.

## Consideraciones para diseño estructural
- Confirmar la tecnología: visible, UV fluorescente u otra.
- Definir qué debe verificarse y con qué método.
- Coordinar ubicación y compatibilidad con tintas, coatings y equipo de impresión.

## Tipos comunes
- Tintas fluorescentes.
- Tintas visibles bajo determinadas fuentes de luz.
- Tintas con respuesta a estímulos específicos.
- Tintas con propiedades de seguridad especiales.

Las características reales dependen de la formulación.
