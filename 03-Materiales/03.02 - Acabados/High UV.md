**Nombre técnico:** High-Gloss UV Coating
[[Barnizadora UV]]

Barniz UV de alto brillo, según la denominación utilizada en la fábrica. Se cura mediante radiación ultravioleta.
![[Pasted image 20261111102535.png]]
## Para qué se utiliza
Aumentar el brillo visual y resaltar superficies impresas.

## Consideraciones para diseño estructural
- Confirmar si la aplicación es general o selectiva.
- Prevenir barniz en áreas de adhesión cuando perjudique el pegado.
- Verificar registro, compatibilidad del material y restricciones del equipo de barnizado.

## Cómo funciona
Se aplica un barniz sobre el material impreso y se cura mediante un sistema UV compatible.

## Diferencia con Spot UV
High UV describe el acabado de alto brillo utilizado internamente; Spot UV describe una aplicación selectiva o localizada. No significan necesariamente lo mismo.
